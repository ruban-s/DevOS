# RedTeam Pairings

## Neighbors in Order

**Line up before a RedTeam run:**
- `research` — collect background, precedents, numbers the critics will need

**Inside the run:**
- narrative decomposition for splitting positions into testable bits
- bespoke critic briefs, each launched as a `general-purpose` worker — the parallel wave

**After the dust settles:**
- `extractalpha` — keep only the highest-voltage objections
- `xpost` — carry the verdict outward

## Working With FirstPrinciples

RedTeam leans on FirstPrinciples twice:

- **Opening split:** run `FirstPrinciples/Deconstruct` so the position separates into bedrock versus guesswork, and the gap between what is said and what is actually there becomes visible
- **Pre-rebuttal sort:** run `FirstPrinciples/Challenge` so every claimed limit gets tagged hard / soft / assumed

The pattern behind the pattern: the blows that land hardest almost always strike a limit everyone treated as physics that turns out to be policy. Say it plainly in the run: "Use FirstPrinciples/Challenge on the stated limits before the parallel wave."

## Answer Shape

- **Build:** fair statement + rebuttal, 8 numbered beats apiece
- **Beat length:** 12–16 words, held strictly — brevity is the discipline
- **Voice:** plain, substantive, no theatre
- **Always carries:** a first-principles pass plus where independent critics converged
- **Never carries:** nits, caricatures, interchangeable objections
