# Rapid Cycle

## Done Looks Like

A small portfolio that genuinely evolved — not a dressed-up familiar list — delivered inside a time box. Lineage preserved throughout, imagination labeled as imagination and evidence as evidence, and the single reality check for a longer run identified.

## The Compact Cycle

Push a compressed population through **CONSUME → DREAM → DAYDREAM → SALON → STEAL → MATE/MUTATE → TEST → SELECT**. Require at least two unrelated disciplinary viewpoints, one deliberately imperfect mechanism transfer, and several parent lineages. Present the result as cycle 1, never as proof.

BeCreative may assist inside CONSUME, DREAM, DAYDREAM, or SALON for fast divergent expansion only; lineage, testing, and selection stay under Novelty's contract throughout.

## Output Contract

Return:

- **Reality frame:** problem, hard constraints, and the one decisive test.
- **Three or more candidates:** different niches, each with lineage, mutation/transfer record, fantasy-or-evidence label, and test status.
- **Selected portfolio:** a leading candidate, a contrarian wildcard, and an account of the diversity retained.
- **Next evolution rule:** what cycle 2 should amplify, suppress, or test.

## Guardrails

Never compress away DREAM, deliberate misapplication, reality testing, or diversity selection. When the time budget can't fund all four, recommend BeCreative for a single-pass brainstorm rather than branding the output an evolutionary run.
